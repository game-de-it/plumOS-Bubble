# スクレイピング

Wi-Fiへ接続し、`START` → `Apps` → `Scraping`から実行します。対象システムを選び、
画面の案内に従ってください。結果はフロントエンドが参照するSD1の画像領域へ保存
されます。

- ROM名を一般的なrelease名へ揃えると検索精度が上がります。
- 画像取得中に電源を切ったりWi-FiをOFFにしたりしないでください。
- 新しい画像が見えない場合は一覧を更新するかフロントエンドを再起動します。
- 失敗時は空き容量、時刻、Wi-Fi、DNSを確認し、`plumos/logs/`を参照します。

SD2のROMを使っている場合も、画像とスクレイピング状態はSD1へ保持されます。
