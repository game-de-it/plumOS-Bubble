# 基本操作と電源・スリープ

## フロントエンド

| 操作 | 動作 |
| --- | --- |
| 十字キー | システム、ゲーム、設定の移動 |
| `A` | 決定／ゲーム起動 |
| `B` | 戻る |
| `SELECT`（ゲーム選択中） | 利用可能なエミュレータ／コアを選ぶ |
| `START` | メインメニューを開く |
| 電源ボタン短押し | 電源メニューを開く |

空のシステムを隠すにはUI設定の`SHOW EMPTY SYSTEM`をOFFにします。ROMの追加・削除後
は一覧を更新するか再起動してください。

## 電源

電源ボタンのメニュー、または`START`メニューから`Reboot` / `Shutdown`を選びます。
ゲームが応答しない場合も、先にエミュレータを終了させてから再起動／終了する処理が
動きます。画面とLEDが消えるまでSDカードを抜かないでください。

## スリープ

電源ボタンの短押しでsleepへ入り、もう一度押すと復帰します。ゲーム中も利用できます。
復帰後は映像、操作、スピーカー／イヤホンの出力先を確認してください。

## 音量と画面

本体の音量－／＋buttonはゲーム中もsystem全体の音量を変更します。`START` →
`システム設定`の`音量`からも同じ値を変更できます。明るさ、contrast、hue、saturationも
システム設定から調整できます。

## 端子

- USB端子: 充電専用
- HDMI端子: 現在未対応
- SYS: 本体上部。起動用SD1
- SD2: 本体下部。任意のROM／BIOSカード
