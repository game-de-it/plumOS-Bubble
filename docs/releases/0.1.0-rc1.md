# plumOS Bubble v0.1.0-rc1

## English

plumOS Bubble v0.1.0-rc1 is the first public release candidate of the
GKD Bubble-specific SD-card Linux distribution.

### Highlights

- controller-driven frontend with 97 system definitions and 196 launch profiles
- RetroArch, PicoArch, standalone emulators, PortMaster and Pyxel integration
- GGFE cartridge frontend and the `SEGA-HCCFL-B3` Game Gear LCD preset
- SD2 ROM/BIOS support, artwork scraping and save/state/screenshot storage
- Wi-Fi with FTP, SFTP and SMB file transfer
- fast power-off, reboot and sleep/resume paths
- signed Runtime update design with downgrade rejection and rollback protection

### Hardware acceptance

The exact decompressed image passed host verification and a physical write to a
GKD Bubble. Hardware checks included first-boot partition provisioning, p2 and
System A/B verification, complete managed checksums, Wi-Fi, Saturn with the
Clang YabaSanshiro build, SD2, shutdown and three clean cold boots.

### Known limitations

- USB is treated as charge-only; ADB is not exposed.
- HDMI output is unsupported.
- Nintendo 3DS and Java ME are not supported.
- N64 performance depends on the game; the Performance governor is recommended.
- ROMs, commercial games and user-supplied game BIOS files are not included.

### Install

1. Download the `.7z` SD image and checksum file.
2. Verify SHA-256, then extract the `.img` file.
3. Write it as a raw image to a good-quality microSD card of at least 16 GB.
4. With the Bubble powered off, insert it into the **top-edge SYS slot**.
5. Power on and wait for first-boot storage preparation to finish.

The optional **bottom-edge SD2 slot** is for ROMs and BIOS files. Insert or
remove SD2 only while powered off. The initial SSH login is `root` / `plumos`;
change it if network services are enabled.

## 日本語

plumOS Bubble v0.1.0-rc1は、GKD Bubble専用SDカードLinuxの最初の公開リリース候補です。

### 主な機能

- 97システム定義・196起動profileを備えたコントローラー操作のfrontend
- RetroArch、PicoArch、standalone emulator、PortMaster、Pyxelの統合
- GGFEカートリッジfrontendとGame Gear用`SEGA-HCCFL-B3` LCD preset
- SD2のROM/BIOS、artwork scraping、save/state/screenshot保存
- Wi-FiとFTP、SFTP、SMBファイル転送
- 高速化した電源OFF、再起動、sleep/resume
- downgrade拒否とrollback保護を備えた署名済みRuntime update設計

### 実機確認

展開後の同一imageをGKD Bubbleの実SDへ書き込み、初回partition作成、p2、System A/B、
全managed checksum、Wi-Fi、Clang版YabaSanshiroによるSaturn、SD2、shutdown、cold boot
3回を確認しました。

### 既知の制限

- USB端子は充電専用として扱い、ADBは表示しません。
- HDMI出力は未対応です。
- Nintendo 3DSとJava MEは非対応です。
- N64はゲームによって性能差があり、Performance governorを推奨します。
- ROM、市販ゲーム、利用者が用意するゲームBIOSは含まれません。

### インストール

1. `.7z`形式のSD imageとchecksum fileを取得します。
2. SHA-256を確認してから`.img`を展開します。
3. 16GB以上の品質の良いmicroSDへraw imageとして書き込みます。
4. 電源OFFのBubbleで、**本体上部のSYSスロット**へ挿入します。
5. 電源を入れ、初回storage準備が完了するまで待ちます。

任意の**本体下部SD2スロット**はROMとBIOS用です。SD2は電源OFFで抜き差ししてください。
初期SSH loginは`root` / `plumos`です。network serviceを使う場合は変更してください。
